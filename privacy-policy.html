Notch Aura Privacy Policy

Last updated: 10 October 2026

Notch Aura ("the app") is developed by Ghawi Apps ("we"). This policy explains what information the app accesses, how it is used, how it is protected, and how long it is retained.

Summary

  • Notch Aura has no account, no advertising and no analytics.
  • We do not operate a server for this app and do not sell user data.
  • App-opening detection, notification-source detection and visual settings are processed on the device.
  • The optional lifetime VIP purchase is handled through Google Play Billing. Google Play processes the transaction under Google's own terms and privacy policy.

Accessibility service ("App activity")

This optional service is used only when the user enables App-opening animations. It detects that a configured app has entered the foreground so Notch Aura can start the visual effect assigned to that app. The service receives the foreground event's app package name and window class name and is configured with canRetrieveWindowContent=false.

  • It does not read screen content, text the user types, passwords, messages or form contents.
  • It does not take screenshots or perform gestures and does not control the device.
  • Notch Aura does not save a history of apps the user opens.
  • Apps the user explicitly chooses to configure, along with their animation settings, are stored locally as user settings. This is separate from the live foreground-detection event stream.
  • Foreground-detection event data is not transmitted or shared.
  • The app shows a separate prominent disclosure and asks for affirmative consent before opening Android's Accessibility settings.
  • The user can turn the service off at any time in Android Settings > Accessibility.

Notification access

Notification access is optional and is used only when the user enables Notification animations. Notch Aura uses the posting app's package name, Android's internal notification key and whether the notification is a group summary to determine which configured visual effect should play and to avoid replaying an effect when an existing notification is merely updated.

  • The app does not read notification titles, message text, images, contacts or replies.
  • Notification-source events are processed on-device and are not transmitted or shared.
  • The app asks for consent before opening Android's Notification access settings.
  • The user can revoke access at any time in Android Settings.

Installed apps list

To let the user choose which apps get an animation, Notch Aura reads the names and icons of the apps that appear in the device's launcher, using Android's package manager. This list is shown only inside the app; it is not stored or transmitted. Only the apps the user explicitly configures are saved, as described under “Information stored on the device”.

Display over other apps

This permission lets Notch Aura draw the selected visual effect around the camera cutout, notification-bar area, screen edge or full screen while another app is visible. The overlay is non-interactive and is not used to capture or inspect the content underneath it.

Foreground service and start at boot

When Notch Aura is enabled, Android may keep its visual-effect service running in the foreground so configured effects can respond to app opens, notifications and phone unlocks. The service can be stopped by turning Notch Aura off. Android also provides system controls for active foreground services. If the user left Notch Aura enabled, the app may restore the service after a device restart where Android permits it.

On Android 13 and later, Notch Aura asks for notification permission once, when the user turns it on, only so this “Notch Aura · Active” notice can appear in the notification shade. Notch Aura posts no other notifications. If the user declines, the effects still work and Android still provides its system foreground-service/active-app indication.

Google Play Billing

The optional lifetime VIP is sold through Google Play Billing.

  • Google Play handles the payment screen and payment details. Notch Aura does not receive card or bank details.
  • The app receives product ownership/purchase state so it can grant, restore or remove VIP access.
  • A purchase token can be used transiently to acknowledge a completed purchase. Notch Aura does not persist the token in its own settings.
  • The Google Play Billing Library adds Android's Internet and network-state permissions. They are used only by that library to communicate with Google Play; Notch Aura's own code makes no network requests and sends nothing to the developer.
  • “Rate Notch Aura” only opens the app's page in the Google Play Store app.

Purchase processing is subject to Google's privacy policy and Google Play terms. See Google's privacy policy.

Information stored on the device

Notch Aura stores app-private settings including apps the user explicitly configured; selected effects, colours, size, speed and display time; camera calibration and other visual preferences; feature toggles; which Batch run each configured app was added in, so the app list can show one tab per batch; how many times the app was opened, used only to ask once for a Google Play rating; a Google Play review code, only if one was entered in Settings > Review access (checked on the device and never sent anywhere); and a local cache of the VIP entitlement so the UI can reflect the last verified purchase state.

These settings stay in app-private storage. Android's normal backup system may include app preferences in the user's device/account backup; we cannot access that backup.

Security

Notch Aura minimizes access by requesting only the Android capabilities needed for its visible features. Accessibility window-content retrieval is disabled. App-opening and notification-source processing occurs locally, and the app does not operate a developer backend for this data. Google Play purchase traffic is handled by Google Play's billing system.

No software can guarantee absolute security. If the app's data handling changes, this policy and the Play Data safety declaration must be updated before the changed version is published.

Retention and deletion

We do not maintain a server-side profile or account for the user. Local settings remain until the user resets them, clears the app's storage or uninstalls the app. The app's Reset all settings control removes Notch Aura's locally stored configuration. Uninstalling also removes the app's local data, subject to any separate Android backup retained by the user's Google account under Android's own backup controls.

Google Play retains transaction records according to Google's policies; those records are not held on a Notch Aura server.

Children

Notch Aura is not directed at children under 13 and does not knowingly operate a service that collects children's personal information.

Changes to this policy

If this policy changes, the updated version will be published at the same public privacy-policy address with a revised Last updated date.
